# Hosp-Project-2026
การพัฒนาโปรแกรมการเฝ้าระวังและติดตามการทำงานเครื่องมือจ่ายกลาง

## การทำงานของหน้าต่าง UI ในโปรแกรม

1. ดูสรุปรายการคงเหลือของเครื่องมือและ Set อุปกรณ์ทางการแพทย์รายวัน
    - สามารถกดดาวน์โหลดไฟล์เป็นตาราง Excel
    - พิมพ์เป็นเอกสารสรุปรายการเครื่องมือประจำวัน
    
2. ติดตามเครื่องมือและ Set อุปกรณ์ทางการแพทย์

    - สามารถดูแผนกที่ทำการยืมเครื่องมือและ Set อุปกรณ์ทางการแพทย์
    - กดตรวจสอบเพื่อดูรายการที่แผนกนั้นยืมรายการอะไรไปบ้าง
    
3. การบันทึกการรับคืนและจ่ายเครื่องมือและ Set อุปกรณ์ทางการแพทย์
    - สามารถทำการอัพโหลดไฟล์ .xlsx และ .csv เพื่อทำการบันทึกรายการคงเหลือของเครื่องมือและ Set อุปกรณ์ทางการแพทย์
    - แสดงตัวอย่างของไฟล์ที่ทำการอัพโหลด
    
4. การบันทึกเครื่องมือและอุปกรณ์ทางการแพทย์ที่ชำรุด
    - สามารถทำการอัพโหลดไฟล์ .xlsx และ .csv เพื่อทำการบันทึกเครื่องมือและอุปกรณ์ทางการแพทย์ที่ชำรุด
    - แสดงตัวอย่างของไฟล์ที่ทำการอัพโหลด
    
5. การขอเบิกวัสดุและเครื่องมือการแพทย์
    - สามารถกดเพิ่มรายการวัสดุและเครื่องมือการแพทย์ และจำนวนที่ต้องการเบิก
    - เมื่อกดส่งข้อมูลการเบิกแล้ว จะส่งแบบฟอร์มไปให้คลังของโรงพยาบาลเพื่อทำการขอเบิกต่อไป
